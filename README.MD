# Pre-entrega 9 — Cafetería de Santi

Simulador de compra para una cafetería, desarrollado con HTML, CSS y JavaScript.

## Funcionalidades

- Muestra productos disponibles.
- Permite agregar productos a un pedido.
- Calcula el total de la compra.
- Muestra un cupón de descuento luego de 3 segundos mediante `setTimeout()`.
- Maneja errores al intentar finalizar una compra sin productos.
- Utiliza `try`, `catch` y `finally` durante el proceso de compra.

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo usarlo

1. Abrir `index.html` con Live Server.
2. Esperar unos segundos para ver el cupón.
3. Agregar productos al pedido.
4. Finalizar la compra.
5. Probar finalizar sin productos para verificar el manejo de errores.
